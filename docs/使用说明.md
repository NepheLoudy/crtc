# 杜博夫赛事系统 · 使用说明

> 面向参赛队员与裁判。网页地址以现场公布为准（示例：`http://192.168.31.57:8321`）。
> 账号与密码由组委会统一发放，**不开放注册**。观众无需登录即可在「排名大屏」观看全部实时数据。
> 完整比赛规则（条款 5.1–5.3.5 与三天赛程表）见系统内「**使用说明 → 比赛规则**」标签，或仓库 `docs/比赛规则.md`。

---

## 一、参赛队员须知

### 1. 登录

1. 打开赛事网页，点右上角「**裁判登录**」。
2. 输入组委会发放的**队员账号与密码**（每个账号已绑定本队）。
3. 登录后左侧出现「**我的比赛**」页——这是队员的专属页面。
4. 同一账号在别处登录会把当前登录顶下线（防账号共享），属正常现象，重新登录即可。

### 2. 能看什么

| 页面 | 内容 |
| --- | --- |
| 我的比赛 | 本队当前排名、积分、ARO、胜-平-负、本轮对阵（对手与局号、场地、批次时间）、我的申请记录 |
| 瑞士轮 / 淘汰赛 | 全部对阵与结果，实时更新（只读） |
| 排名大屏 | 投屏视图，适合全场观看 |

### 3. 能申请什么（条款 5.3.4）

在「我的比赛」页提交，填写理由后等待管理员处理。**队员没有任何成绩编辑权限**——比分、对阵、排名均由裁判与管理员操作，申请也由管理员批准后才生效。

| 申请 | 效果（批准后） | 限制 |
| --- | --- | --- |
| **场次调换** | 本队本轮对局排至**本轮最后一局** | 需本轮对阵已生成、且本队该局尚未录入结果 |
| **弃赛** | 本队**本轮判负**，并退出后续所有轮次（排序中删除） | 不可撤销，请务必先与组委会当面确认 |

申请状态在「我的比赛」页可见：待处理 / 已批准 / 已拒绝。

### 4. 积分与名次规则（速览）

- 每轮胜 **3** 分、平 **1** 分、负 **0** 分；共 6 轮瑞士轮（BO1）。
- 名次按「积分 → ARO（对手强度）」排序；前 8 名进入 8 强车轮战淘汰赛（BO3）。
- 全部操作留有审计记录，成绩可追溯，对结果有疑问请联系组委会。

## 二、裁判操作手册

### 1. 登录与权限

- 右上角「裁判登录」，使用组委会发放的**裁判账号**。
- 裁判权限 = **录入成绩**：每轮结果、确认轮次、淘汰赛录局、决赛录入。
- 裁判**不能**：生成/重排对阵、修改名册、处理退赛、改规则、撤销操作——这些是管理员职责。

### 2. 瑞士轮成绩录入（第 1~6 轮）

1. 进入「**瑞士轮**」页，核对本轮对阵表（局号 × 队伍）。局号下方标注场地与批次时间（局 01–16 在 A 场、局 17 起在 B 场，左红右蓝）；管理员可点局号旁 ↑↓ 手动调序，批次/场地/时间随新局号重算；需要发群/打印点右上角「**⬒ 渲染导出**」（CRTC 风格对阵卡，可存图片或 Ctrl+P 存 PDF；?venue=A|B 可只出单场地表）。
2. 每局中间有三个按钮「**胜 | 平 | 胜**」：**左边的「胜」= 红方获胜，右边的「胜」= 蓝方获胜**（左红右蓝，队伍名旁有方章），「平」= 平局。按纸质记分表核对后点击。
3. 录错随时重按覆盖，或点该局右侧「**↺ 重赛**」：清除已录结果，该局调至本轮最后一局（其余局次前移）当场重打——**确认本轮之前**都可修改。管理员的重赛菜单里还可选「**下轮再重赛**」：本轮暂记平局保障赛程，下一轮强制对位出真结果（条款 5.3.6）。
4. 全部对局录入后，点「**确认本轮成绩，结算 ARO**」。确认后积分与 ARO 立即结算并推送到所有屏幕，确认后的修改需要联系管理员（管理员可撤销）。
5. 对局卡片显示「**弃赛判负**」的是系统按条款 5.3.4 自动判负的场次，无需录入；其余场次必须全部录入，「确认本轮」按钮才会亮起。

### 3. 淘汰赛录局（8 强车轮战 + 决赛）

1. 进入「**淘汰赛**」页，A / B 两组控制台各自独立计分。
2. 当前对阵为「防守方 ◆ vs 进攻方 ▲」，中间菱形格显示已录局数。每打完一局点对应按钮：**◆ 防守胜 / 平局 / 进攻胜 ▲**。
3. 一方先胜 **2 局**该场自动结算：积分增减、败方回队列、下一场自动开启——录局的裁判无需做任何额外操作。
4. 每场 3 局制：先胜 2 局赢；**平局=双方均失败该局**（不计胜局）；打满 3 局无人 2 胜为**平场**——双方各 -0.5 积分，进攻方回队尾。
5. 决赛同理，先胜 2 局者夺冠，录完自动进入颁奖页与最终名次。

### 4. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 「确认本轮」按钮是灰的 | 还有对局未录入结果 |
| 点按钮提示「权限不足」 | 该操作属管理员（如生成对阵、退赛）；请联系管理员 |
| 弹出「需要登录」 | 会话被同账号别处登录顶下线，重新登录即可 |
| 录错结果且已确认本轮 | 联系管理员撤销后重新录入 |
